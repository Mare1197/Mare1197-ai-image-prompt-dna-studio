# UI and Workspace

## Visual direction
Refined dark creative workspace: deep graphite/black and midnight purple with controlled purple, cyan and pink accents. Themes: Mage purple, graphite/teal/electric-blue/acid-lime, black/bright-green, high-contrast dark and clean light. Reduced-motion option; animated backgrounds use subtle colors only.

## Layout
- Compact collapsible permanent left navigation
- Optional contextual resizable/pinnable left panel
- Center workspace
- No permanent right inspector
- Advanced controls in floating, resizable, pinnable drawers/popovers
- Pinned panels on one side extend or split that side rather than overlap
- Resizable bottom prompt dock slightly left of center

## Navigation
Home, Prompt Architect, Prompt DNA, References, Characters, Monsters, Vehicles, Styles, Effects, Locations, Camera, Lighting, Wardrobe, Presets, History, Results, Banks, Workflows, Settings.

## Prompt dock
Raw prompt, Rewrite, Improve, Build, Positive Reframe, Repair, Save, Copy, Variations, explicit Generate, model, aspect ratio, references and locks. Multi-line, expandable and keyboard-friendly.

## Controls
Compact aspect buttons with 16:9 default; include 1:1, 4:5, 3:4, 2:3, 3:2, 16:9, 9:16 and 21:9. No sampler/scheduler/guidance/reference-strength controls.

## Tag interaction
Normal click selects, modifier-click locks, right-click excludes. Support multi-select, category locks, preserve/change/randomize checklists and visible non-color-only status indicators.

## Image history
Batch rows, preview-size slider, adaptive images per row, enlarged viewer, bottom thumbnails, arrow-key looping, Escape close, side-click navigation, compare 2/4, prompt diff, favorite, rating, save as reference/preset and result notes.

## Persistence
Remember every panel, overlay, menu, filter, theme, preview-size and workspace state.

## Accessibility
Keyboard navigation, visible focus, screen-reader labels, tooltips, high contrast, reduced motion, undo/redo and clear errors.
