# Acceptance Criteria

The project is complete only when verified:

1. Rough input converts to valid Prompt DNA and a coherent clean prompt.
2. DNA edits update the prompt live.
3. Every field supports required lock/change/exclusion/randomization states.
4. Five default variations are meaningfully distinct and preserve locks.
5. History tree, loading, diffs, restore, ratings, favorites and export work.
6. Multiple references with roles and selective extraction work.
7. Characters and monsters can be created, saved, loaded and kept consistent.
8. Adult wardrobe contains approved lingerie, skirts, mini-skirts, heels, Vans and similar slim sneakers.
9. Thick/platform/chunky footwear is blocked in banks, imports, presets, randomization, composer, lint and result review.
10. Human and monster subjects remain distinct.
11. Full approved vehicle library exists.
12. Cars support drift/heavy/track/street/widebody/show/luxury/futuristic modifications.
13. Paint, wrap, livery and decals are independent and lockable.
14. Positive reframing and conflict resolution work and explain adjustments.
15. Prompt scoring and lint/repair work.
16. Presets can partially apply without overwriting unrelated locks.
17. Result feedback creates a linked next iteration and lessons.
18. Local data survives reload and backup/restore/import/export work.
19. Layout, filters, themes and preview settings persist.
20. Image history supports size slider, adaptive rows, enlarged viewer, keyboard loop and 2/4 compare.
21. Editable workflows, approval/audit history, undo/redo and restore work.
22. ChatGPT Images and Nano Banana Pro adapters are separate from universal DNA.
23. App works in prompt-only mode without provider credentials.
24. Only active clean prompt is submitted to providers.
25. All user text is rendered safely.
26. Accessibility and responsive behavior are verified.
27. Tests pass or remaining failures are honestly documented.
28. Documentation includes architecture, data model, current state, testing, known issues and next phase.
