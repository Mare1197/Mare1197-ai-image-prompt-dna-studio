# History, References and Results

## Prompt history
Original input is `0P`. Major rewrites use `V1`, `V2`... Branches use parent + short direction + sequence, such as `V1-Cinematic-1` or `V2-Wrap-1`.

Each record stores ID/title/parent, DNA, clean prompt, adapter, references, locks, changes, rating, favorite, notes and timestamps. Support tree, timeline, list, search, filters, diff, restore, duplicate and export.

Commands/actions: save, history, load, favorite, rate 1–5, notes, export history, compare, branch and restore. Shorthand such as `/load V3 C` may resolve only when unambiguous.

## References
At least four active references with architecture for more. Roles: whole composition, identity/face/body, wardrobe/lingerie/footwear/pose, monster design/surface, vehicle model/shape/body kit/wheels/paint/wrap/livery/decals, camera, lighting, palette, environment, texture, mood and style.

Each has role, weight, priority, lock, include/ignore, crop/focus and notes. Selective extraction may populate only chosen DNA fields and cannot overwrite unrelated locks.

## Result feedback
Evaluate characters, count, identity, wardrobe, lingerie, footwear and sole thickness; monster type/scale/anatomy/separation; vehicle/model/modifications/wheels/stance/paint/wrap/livery/decals; composition/camera/light/style/effects/environment; technical and creative quality.

The feedback loop records successes/failures, suggests the smallest useful correction, offers successful-field locks and creates a linked next branch. Separate global, project, preset and model-specific lessons with confidence labels.

## Copy/export
Copy clean prompt, adapter prompt, DNA, positive reframing, tags, locks, variations, full prompt pack, history, preset and result notes. Export plain text, Markdown, JSON, Prompt DNA JSON, project package, history and presets.
